# Standing deviations

Scope-wide suppressions require review under EN-00.5 and count against the
per-language ceiling under EN-00.6.

| Check | Scope | Rationale | Risk and mitigation | Approval | Review by |
|---|---|---|---|---|---|
| readability-magic-numbers | tests/ | EN-04.7, the exemption CXX-02.8 names explicitly. A literal size, offset or count in a test is the case under test, not a value shared with production code; hoisting it to a named constant moves the expected value away from the assertion that reads it. The test tree sits outside `src/` (`CXX-13.2`), so the `src/` row does not reach it and this row states it, in the library-owned overlay. | A wrong expected value can agree with a defect in the implementation. Assertions compare behavior with the literal; review checks the expected value against the requirement or protocol, and other enabled checks remain active. | approved by the maintainer, 2026-10-29 | 2027-07-13 |
| readability-magic-numbers | src/ | CXX-02.8. Included dependency headers transcribe report lengths, field offsets and masks from the wire format. Diagnostics inherit the including translation unit's scope; introducing names in this repository cannot change those header definitions. | A wrong dependency constant can escape this check. Dependency decoder and report-length tests exercise these definitions; review compares changed pins and the local driver's use against the cited vendor protocol. | approved by the maintainer, 2026-10-29 | 2027-07-13 |
